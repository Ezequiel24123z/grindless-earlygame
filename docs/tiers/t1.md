# T1 - Voltaic first factory

T1 development is owner-authorized in parallel with testing the installed T0
development candidate. It is not T0 acceptance, a release candidate, a deployed
T1 build or an instant player unlock. The existing world-scoped **Relay quest
claim** still precedes the T1 quest chapter; manufacturing itself uses physical
components, not global permissions.

## Implemented contract

[`T1Progression`](../../common/src/main/java/io/github/ezequiel24123z/grindless/progression/T1Progression.java)
declares production lines and selects live authority IDs for runtime teaching
and source-bound export. It owns no recipe quantities, durations, energy rates,
fluid amounts, catalyst counts or output ratings. Those stay in
[`ProcessGraph`](../../common/src/main/java/io/github/ezequiel24123z/grindless/recipe/ProcessGraph.java),
[`T1Recipes`](../../common/src/main/java/io/github/ezequiel24123z/grindless/recipe/T1Recipes.java),
the shipped crafting JSON and the existing T0 catalogues.

| Line | Role | Source-backed outcome |
| --- | --- | --- |
| `power` | Mandatory | Thermal generation from mod-owned biomass and the first pylon |
| `milling` | Mandatory | Pulverizer preparation of the renewable T0 iron/copper feed |
| `reduction` | Mandatory | Arc reduction of that feed; slag and discharged CO remain explicit |
| `glass` | Mandatory | Electric sand preparation and glass, without making a vanilla block generator mandatory |
| `forming` | Mandatory | Press, retained dies, iron forms, copper coil and structural casing |
| `assembly` | Mandatory | Construct the Assembler and reproduce the existing F1 Matrix batch |
| `relay_f2` | Exit | Consume the prior physical F1 Matrix, casing, glass and Flux Cell to produce the rated F2 Matrix |
| `extraction` | Optional | Scanner and finite-vein extraction; not canonical renewable supply |
| `logistics` | Optional branch | Existing belts and junctions, not a new transport engine |
| `storage` | Optional branch | Grid links, buffering and transformation |
| `kiln` | Optional branch | Existing roast/oxide alternatives, not a mandatory acid line |
| `factory_space` | Optional branch | Building space, never the F2 manufacturing prerequisite |

The first hand-crafted Matrix batch remains unchanged. Its controllers fund the
Thermal Generator, Pulverizer, Arc Furnace, Press and Assembler. Dies are
non-consumed catalysts. The T1 coil uses the Press; the Wire Mill remains a
later route and must not become a dependency of the first factory.

## Runtime and export seam

`lines()` and `byId()` return the shared catalogue. `byQuest()` maps existing
task identities to their line; `questRouteIds()` selects actual authority IDs.
`atlasForQuest()` projects the supplied live Atlas entries and fails if an
expected row is missing. The thermal fuel row is returned separately in
`nonAtlasRouteIds`, because generator-fuel authorities are not Atlas recipes.
This is not permission to invent a viewer row or silently omit a required craft.
The glass lesson selects the actual geological/biomass/water and primitive-metal
upstreams as well as electric sand/glass, so its reusable feed is visible instead
of recommending a permanent vanilla farm.

The already-shipped [Flux Cell craft](../../common/src/main/resources/data/grindless/recipes/flux_cell.json)
is now mirrored in the existing T1 crafting catalogue, so the common Atlas can
explain the real F2 coupling component. Its JSON, quantities and item ID are
unchanged. The normal authority adapter still reads that JSON and rejects a
catalogue mismatch; the catalogue alone is not evidence of the shipped craft.

## Proof boundaries

The existing conditional T0 audit, renewable geological/biological routes and
finite construction replay remain their own source-bound evidence. An
implemented T1 route is not automatically an unlimited-supply certificate,
whole-tier closure, factory power/autonomy proof or a played Survival result.
In particular, the audit model's untagged/default-F1 resource identity and its
explicitly rated F1 upgrade input must not be conflated without proof.

No new recipe engine, planner, currency state machine, parametric port system,
world permission, ore generator or mandatory Factory World is introduced here.
The installed T0 JAR/ZIP, Prism instance, worlds and launcher remain untouched.
