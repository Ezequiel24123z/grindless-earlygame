The official Forge server, Architectury jar and checksum/signature-verified Portable Git used
locally are development dependencies in ignored build/run directories, not tracked upstream
source or art. Their installation does not change Grindless's MIT-authored code licence or

An actual import row must name the exact files and revision, owner/licence scope, modifications,
required notices, redistribution consequence and reviewer. Add the matching notice entry and
required licence texts in the **same commit** as that import. No candidate is implicitly approved
because its repository has a familiar licence badge.
