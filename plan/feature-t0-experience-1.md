- **REQ-007**: Add bounded truthful machine inspection and optional exact-version overlay integration; no loader types in common.
- **REQ-008**: Replace inappropriate synthetic distribution with justified physical audio or documented silence; preserve Quern/Mixer and all historical spend evidence.

- **REQ-010**: Export source-bound production/balance evidence and opt-in local aggregate developer telemetry without personal information.
- **REQ-011**: Produce the requested inventory, quest/production maps, balance/audio/visual manifests, interface specification, playthrough protocol, issue template and return handoff.
- **REQ-012**: Pass the complete required gate before using `TECHNICALLY PREPARED FOR LONGITUDINAL HUMAN VALIDATION`; real client checks are distinct from server/fixture evidence.
- **SEC-001**: Never print/copy/commit credentials, private host paths, unrelated workflows or personal telemetry.
- **SEC-002**: Never reboot, weaken security, expose Comfy publicly, delete owner worlds or adopt an old exploratory save.
- **CON-001**: Forge1.20.1/Java17 is the compiled target; historical NeoForge compatibility is not a newly executed second-loader pass.
- **CON-002**: No new mandatory dependency, fundamental currency, license obligation, save reset, copied ambiguous material, release/tag or unrestricted T1 development without the owner's decision.
- **CON-003**: New sound purpose allows at most8 POSTs/4 families, initially6/3, without resetting old ledgers; new local visual purpose allows at most6 candidates/3 targets.
- **CON-004**: One mutating shared PC JVM/cache/deployment owner at a time; independent CPU-only visual processing uses its explicit isolated root.
- **GUD-001**: Prove reusable mechanisms deeply, validate content broadly and rerun only affected evidence before the meaningful full integration gate.
- **PAT-001**: Java catalogues remain recipe/quantity authorities; native stores/claim ledgers remain the actual owners, not generated reports or external quest rewards.

## 3. Alternatives

- **ALT-001**: A new minted currency/wallet is rejected for this cycle; direct in-kind exchange satisfies recovery/surplus sinks without a fundamentally new economy authority.
- **ALT-002**: Replacing the tank engine or implementing a generic all-tier multiblock kernel is rejected; extend native storage and the two existing bounded shapes.
- **ALT-003**: Deleting Guide IDs or resetting old claims is rejected; registered deprecated behavior and additive quest metadata preserve worlds.
- **ALT-004**: A screenshot/contact-sheet or server boot as a substitute for actual client interaction is rejected.
- **ALT-005**: Increasing costs/waits or shrinking the starter merely to claim complexity is rejected; document source costs and gather causal pacing evidence first.

## 4. Dependencies
